# ReactPulse


React Pulse is a interactive guide to how React renders, updates, and thinks.

**Live Demo:** https://react-pulse-five.vercel.app



### 🚀 Getting Started

1.  **Clone the repository:**

2.  **Install dependencies:**
   

    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```
